# DDM1 (ISW-012) - Desenvolvimento para Dispositivos Móveis I

Materiais e exemplos de apoio da disciplina Desenvolvimento para Dispositivos Móveis I (DDM1 - ISW012) - Fatec Rubens Lara

## Conteúdos
- Fundamentos da linguagem Dart
- Orientação a Objetos em Dart
- Mixins e Arrow Functions
- Introdução ao Flutter
- Estrutura básica de aplicações Flutter
- Widgets básicos
- Organização de layouts com Row e Column
- Botões, alinhamentos e listas
- Gerenciamento de estado
- Consumo de APIs REST
- Navegação entre telas
- Persistência local de dados

## Organização

Este repositório reúne exemplos, códigos de referência e materiais utilizados ao longo da disciplina.

Os exercícios e atividades dos alunos são desenvolvidos em repositórios próprios, individuais ou em grupo, conforme orientação em aula.

## Observação

Nem todos os exercícios trabalhados em aula terão soluções disponibilizadas neste repositório.
